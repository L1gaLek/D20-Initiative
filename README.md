# D20 Initiative

## Деплой

Кроме заполнения новых переменных окружения:

1. Выполнить `npm ci`.
2. Выполнить `npm run config`.
3. Выложить сгенерированный `client/runtime-config.js`, но не публиковать `.env`.
4. Убедиться, что директория `packages/` включена в деплой.

Playwright и Chromium на production устанавливать не требуется. Backend, схема БД и порты не изменились.
