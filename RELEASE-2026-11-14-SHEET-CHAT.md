# Sheet navigation and message notifications — 14 November 2026

- The Ally/Enemy selector now sits beside the sheet title, without a visible caption or an Apply button. Changes save immediately through the existing authorized access endpoint. The owner and GM retain their existing permissions; failed saves restore the confirmed value and display an error.
- Sheet tabs and scroll positions belong to the local viewer and the individual character. Incoming room snapshots no longer select a tab through their stale `_activeSheetTab` field. Both character and monster layouts capture their current DOM selection before a refresh, preserve it when reopened, and avoid copying another character's selection.
- Delayed spell/combat refreshes cannot replace another tab or another character's content. Monster lookups carry a render generation, so an old response cannot overwrite a newer sheet, including a reopened sheet for the same token. Repeated renders no longer accumulate root interaction listeners. JSON imports verify the current character and edit permission after reading the file.
- Save Base and Load Base share a row with the JSON file picker, with wrapping on narrow screens.
- New unread room messages show a blinking speech-bubble button in the center of the status bar, alongside the existing Message button highlight. Clicking it opens an unread conversation. A quiet two-note chime plays after browser interaction enables audio. Loaded history, duplicate deliveries, the sender's own messages, and messages read in the visible active conversation do not trigger it; a short cooldown limits bursts. Messages received in a hidden browser tab still count as unread. Reduced-motion settings retain a steady indicator.
